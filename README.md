# 软糯工作台 · 微调迭代说明

## 整体设计概述

本工作台采用**治愈系水彩手绘风格**，专为孕期教师/知识工作者打造，兼顾**工作备课**与**生活记录**双重需求。

---

## 一、界面分层结构（标注说明）

整个界面分为 **4 层视觉架构**：

```
┌─────────────────────────────────┐
│  第1层 · 顶部品牌区 (Top Bar)    │  ← 用户身份、日期、进度
├─────────────────────────────────┤
│  第2层 · 侧边导航 (Sidebar)      │  ← 8 大功能入口
├─────────────────────────────────┤
│  第3层 · 主内容卡片 (Cards)      │  ← 各板块子功能卡片
├─────────────────────────────────┤
│  第4层 · 浮动装饰 (Decorations)  │  ← 贴纸、植物、漂浮元素
└─────────────────────────────────┘
```

### 每张卡片右上角的 `A-xxx / B-xxx` 标签 = 板块内子功能分层标注

## 三、内容数据替换指南

### 📝 替换默认数据（搜索关键词即可定位）

| 数据类型 | 搜索关键词 | 示例 |
|----------|-----------|------|
| 用户昵称 | `小兔叽` | 改为自己的名字 |
| 头像 emoji | `<div class="avatar-bunny">` | 可替换成自己的 SVG 头像 |
| 待办清单 | `var todos=[...]` | 数组形式，可增减 |
| 书籍列表 | `book-title` 类 | 直接修改 div 文本 |
| 笔记内容 | `quote` 类 | 修改引用文字 |
| 运动日志 | `exercise-log-item` | 复制整段 div 即可新增 |
| 三餐规划 | `meal-card` | 替换菜品文字即可 |
| 复盘日期 | `archive-chip` | 修改日期数字 |

### ➕ 新增数据条目

**示例：新增一条待办** — 直接编辑 `var todos=[...]` 数组：
```javascript
var todos=[
  {text:'散步30分钟',done:true},
  {text:'新任务',done:false}  // 新增
];
```

**示例：新增一条读书笔记** — 复制以下模板插入到 `.card` 内：
```html
<div class="note-item">
  <div class="quote">"你想要引用的文字"</div>
  <div class="source">— 《书名》</div>
  <span class="note-tag" style="background:var(--pink-50);color:var(--pink-300);">分类</span>
</div>
```

## 五、设计哲学与平衡

### ✅ 已贯彻的视觉准则

1. **柔和暖色**：以米白、粉、鹅黄、淡蓝为主，无高饱和度色彩
2. **圆润线条**：所有元素采用 `border-radius` 圆角处理，无尖锐棱角
3. **小元素点缀**：贴纸、植物、花朵作为视觉焦点，缓解大量文字的疲劳
4. **工作+生活平衡**：顶部进度条 = 工作效率感，底部花朵装饰 = 生活温柔感

### ⚠️ 避免过度设计

- 卡片阴影保持轻盈（`0.10` 透明度），不堆叠重投影
- 装饰元素保持半透明 (`opacity: 0.4-0.7`)，不喧宾夺主
- 文字层级分明（主色 / 浅色 / 极浅色），不混杂

## 六、技术栈

- **HTML5** + **CSS3**（CSS Variables） + **原生 JavaScript**
- 单文件部署，无外部依赖，可直接双击打开
- 所有图标均使用 **内联 SVG**，无需图标库
- 兼容主流现代浏览器（Chrome/Safari/Edge/Firefox）
